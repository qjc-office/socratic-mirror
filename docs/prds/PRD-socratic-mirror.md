**작성자**: 정상록
**날짜**: 2026-10-02
**상태**: 초안
**이해관계자**: 정상록 (QJC)
**설계 문서**: docs/superpowers/specs/2026-10-02-socratic-mirror-design.md

### 1. 요약 (Executive Summary)
Claude Code 사용자가 자기 과거 대화 기록을 재료로, 반복해서 근거 없이 깔고 있는 전제를 질문만으로 드러내는 공개 플러그인이다. SNS에서 공유된 소크라테스 심문 프롬프트 3종을 각색해 `/socrates` 명령 하나로 쓰게 만든다. QJC의 공개 오픈소스 자산으로 배포한다.

### 2. 배경 및 맥락 (Background & Context)
원본 프롬프트는 ChatGPT의 메모리를 전제로 "지금까지 나눈 대화"를 자료로 쓴다. Claude Code에는 그 자료가 `~/.claude/projects/*/*.jsonl`에 남지만, 사람이 쓴 말은 도구 결과·메타 메시지 사이에 섞여 있다(실측: 38MB 세션 파일에서 user 타입 대부분이 tool_result). 추출과 분석을 분리해야 실제로 쓸 수 있다.

### 3. 목표 및 성공 지표 (Objectives & Success Metrics)

**목표**:
1. 설치 후 명령 하나로 근거 인용이 붙은 전제 제시와 첫 반례 질문이 나온다.
2. 심문 규칙(답 주지 않기, 인정 시 멈춤)이 eval로 회귀 감시된다.
3. 공개 배포에 필요한 안전장치와 개인정보 고지를 갖춘다.

**비목표**:
1. Claude.ai·Cowork 스킬 배포 (수요 확인 후 별도 검토)
2. 사용자 파일 입력(`--file`), 틀별 독립 에이전트, 웹 UI

**성공 지표**:
| 지표 | 현재 | 목표 | 측정 방법 |
|------|------|------|----------|
| pytest 통과율 | 0 | 100% | CI 또는 워커 머신 |
| eval 케이스 통과 | 0/7 | 7/7 | `claude plugin eval` |
| 새 터미널 설치·실행 성공 | 없음 | 1회 이상 기록 | 수동 실행 로그 |
| GitHub 스타 (가정) | 0 | 출시 90일 내 50 | GitHub |

### 4. 대상 사용자 및 세그먼트 (Target Users & Segments)
Claude Code를 일상적으로 쓰며, 일·사업·커리어 판단을 Claude와 자주 의논하는 사람. Job: "내가 반복해서 놓치는 생각의 습관을 누가 정확히 짚어 줬으면 한다."

### 5. 가치 제안 (Value Propositions)
- 과제: 자기 사고의 맹점 발견
- Gains: 자기 기록에 근거한 구체적 질문, 세 줄 정리와 이번 주 액션 3개, 지난번 전제의 재등장 추적
- Pains 회피: 기록 수십 개를 직접 붙여넣는 수고, 위로·일반론만 돌아오는 답변
- 차별점: 실제 대화 기록 기반, 로컬 처리, 세 틀(소크라테스·공자·부처) 교차 검증

### 6. 사용자 스토리 및 요구사항 (User Stories & Requirements)

**P0 -- 필수 (Must Have)**:
| # | 사용자 스토리 | 인수 기준 |
|---|-------------|----------|
| 1 | `/socrates`로 심문을 시작한다 | 인용 1~2개가 붙은 전제 제시와 반례 질문 1개 |
| 2 | 심문 중 조언을 요구해도 질문만 받는다 | 답·조언·위로·칭찬 0건 |
| 3 | 전제를 인정하면 끝난다 | "아포리아" 선언 후 추가 발화 없음 |
| 4 | `/socrates close`로 정리한다 | 세 줄과 액션 3개, 로그 기록 |
| 5 | 위기 신호에서 보호받는다 | 역할 중단, 상담 안내, 재개 없음 |
| 6 | 기록에서 시크릿이 노출되지 않는다 | 패턴 6종 마스킹, 인용 직전 재검사 |

**P1 -- 권장 (Should Have)**:
| # | 사용자 스토리 | 인수 기준 |
|---|-------------|----------|
| 1 | `/socrates triad`로 세 틀 교차 검증 | 틀별 결론 표시, 일치할 때만 삼중 아포리아 |
| 2 | 영어 사용자도 쓴다 | 입력 언어로 응답 |
| 3 | 범위를 넓힌다 | `--days`, `--all-projects` 동작 |

**P2 -- 선택 / 향후 (Nice to Have)**:
| # | 사용자 스토리 | 인수 기준 |
|---|-------------|----------|
| 1 | 지난번 무너진 전제의 재등장 알림 | 로그 대조 결과 표시 |

### 7. 솔루션 개요 (Solution Overview)
- 7.1 UX: 터미널 명령 `/socrates [close|triad] [--days N] [--all-projects]`
- 7.2 핵심 기능: 기록 추출 스크립트, premise-miner 서브에이전트, 심문 규칙 스킬
- 7.3 기술 접근: Python 3 표준 라이브러리, Claude Code 플러그인 + 단일 저장소 마켓플레이스
- 7.4 가정: jsonl 형식이 당분간 유지된다(깨지면 종료 코드 3으로 감지)
