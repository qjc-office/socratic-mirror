# socratic-mirror 설계 문서

- 작성일: 2026-10-02
- 상태: 승인됨 (2026-10-02, 정상록)
- 등급: M (새 플러그인, 파일 약 8개, 외부 공개 배포)
- 출처: SNS에서 공유된 "소크라테스 심문" 프롬프트 3종을 각색. "하버드 교수" 등 확인되지 않은 출처 문구는 쓰지 않는다.

## 1. 목적

Claude Code 사용자가 자기 과거 대화 기록을 재료로, 반복해서 근거 없이 깔고 있는 전제를 질문만으로 드러내고 무너뜨리는 경험을 명령 하나로 얻게 한다.

### 사용자 결정 사항 (브레인스토밍 확정)

| 항목 | 결정 |
|---|---|
| 대상 | Claude Code 사용자 |
| 자료 | `~/.claude/projects/*/*.jsonl` 과거 세션 기록. 기본 범위는 현재 프로젝트 최근 30일, 옵션으로 확대 |
| 배포 | 공개 GitHub 마켓플레이스 (`qjc-office/socratic-mirror`), MIT |
| 언어 | 사용자 입력 언어로 한국어·영어 자동 전환 |
| 구조 | C안: 기록 분석은 서브에이전트, 심문 대화는 메인 세션 |
| 추출 스크립트 | Python 3 표준 라이브러리만 사용 |
| 심문 로그 | 남긴다 (`~/.socratic-mirror/log.md`) |

### 성공 기준

1. 설치 후 `/socrates` 한 번으로 근거 인용이 붙은 전제 제시와 첫 반례 질문이 나온다.
2. 심문 중 답·조언·위로·칭찬을 하지 않는다.
3. 사용자가 인정하면 "아포리아"를 선언하고 추가 발화 없이 멈춘다.
4. 위기 신호에서는 역할을 즉시 중단하고 상담 연락처를 안내한다.
5. 기록 원문은 로컬에서만 읽고, 플러그인 자체는 어떤 외부 전송도 하지 않는다.

### 범위 밖 (Non-goals)

- Claude.ai·Cowork용 스킬 배포 (나중에 별도 검토)
- 사용자가 직접 넣는 자료 파일(`--file`) 지원
- 틀(소크라테스·공자·부처)별 독립 서브에이전트
- 웹 UI·대시보드

## 2. 구조

```

├─ .claude-plugin/
│   ├─ plugin.json
│   └─ marketplace.json            ← 저장소 하나가 마켓플레이스를 겸함
├─ commands/socrates.md            ← /socrates [close|triad] [--days N] [--all-projects]
├─ skills/socratic-inquiry/
│   ├─ SKILL.md                    ← 모드 3개 규칙, 멈춤 조건, 안전장치, 언어 전환
│   └─ references/lenses.md        ← 엘렌코스·정명·십이연기 운용법과 질문 예시(한·영)
├─ agents/premise-miner.md         ← 추출본에서 반복 전제 후보와 인용 반환
├─ scripts/extract_history.py      ← jsonl에서 사람이 쓴 말만 추출
├─ scripts/redact.py · append_log.py · safe_io.py  ← 마스킹 · 로그 기록 · 비공개 파일 쓰기
├─ tests/                          ← pytest + 가짜 jsonl 픽스처
├─ evals/                          ← claude plugin eval 케이스
└─ README.md(영어, 기본) / README.ko.md / README.zh.md / LICENSE
```

### 2.1 extract_history.py

- 입력 인자: `--days N`(기본 30), `--all-projects`(기본 끔, 끄면 현재 프로젝트만), `--max-chars`(기본 60000). 테스트·고급 사용자용으로 `--projects-dir`(기본 `~/.claude/projects`, 환경변수 `SOCRATIC_MIRROR_PROJECTS_DIR`), `--cwd`, `--out`(권한 600 파일로 원자적 교체), `--out-dir`(실행마다 고유한 600 파일을 만들고 경로를 출력, 1시간 넘은 `extract-*.txt` 잔여분 정리)을 둔다. 인자·쓰기 오류는 종료 코드 64.
- 범위 판정: 폴더 이름 규칙은 CLI 버전마다 달라(실측) 쓰지 않는다. 기간 안(파일 수정 시각)의 세션 파일 중 대상 경로 문자열이 들어 있는 파일만 빠르게 고른 뒤(원문 바이트 검사), 기록 줄마다 그 줄의 `cwd`로 판정한다. git 저장소 안에서 실행하면 git 루트와 같거나 그 아래, 밖이면 실행 폴더와 정확히 같은 경로만 포함한다. `cwd`가 없는 줄은 제외한다. 세션 중간에 다른 폴더로 `cd`한 발화도 이 규칙으로 나뉜다. 심볼릭 링크인 폴더·파일은 읽지 않는다. 일치 파일이 없으면 종료 코드 2.
- 남기는 줄: `type == "user"`이고, `isMeta`가 아니며, `isSidechain`이 아닌 것. `message.content`가 문자열이면 그대로, 리스트면 `type == "text"` 블록만 쓴다.
- 버리는 내용: `tool_result` 블록, `<command-name>`·`<local-command-*>`·`<system-reminder>`·`<task-notification>` 등의 태그 블록, 빈 문자열.
- 마스킹(`redact.py`): 토큰 형태(`sk-…`, `ghp_…`, `github_pat_…`, `xox?-…`, `AKIA…`, JWT, `Bearer …`)와, 키 이름에 KEY·TOKEN·SECRET·PASSWORD가 든 대입·JSON/YAML 키의 값을 `[REDACTED]`로 바꾼다. 따옴표 값은 이스케이프를 따르고, 따옴표 없는 값은 줄 끝까지 가린다. 콜론 형식은 복합 이름(snake·kebab·camelCase)이나 password일 때만 가려 일반 문장(`key: …`)은 남긴다. 범위 밖(합의): 키 문맥 없는 맨 토큰, 여러 줄로 나뉜 값(YAML block scalar 등). 정규식 입력은 4,000자 창으로 제한하고 키 시작 경계를 둬 선형 시간을 유지한다.
- 출력: 첫 줄 `# socratic-mirror: N utterances, S sessions, scope=…, days=…, omitted=…, malformed=…, oversized=…, unreadable=…`, 이후 `YYYY-MM-DD | 세션ID 앞 8자 | 발화`가 시간순. 메모리는 최신 발화만 담는 힙으로 상한 근처에 묶고, 상한보다 긴 한 줄도 잘라서 최소 1줄은 낸다. 200만 자 넘는 jsonl 줄은 통째로 올리지 않고 건너뛴다(`oversized`).
- 오류 처리: 깨진 JSON 줄·형식이 다른 레코드는 건너뛰고 건수만 집계하며, 읽을 수 없는 파일은 그 파일만 건너뛴다(`unreadable`). 대상 파일이 있는데 추출이 0건이면 표준 오류로 "기록 형식이 바뀌었을 수 있음" 경고를 내고 종료 코드 3을 돌려준다. Python이 없으면 커맨드가 설치 안내를 띄운다.

### 2.2 premise-miner 에이전트

- 도구: Read뿐이다. 추출은 스킬이 먼저 실행하고 파일 경로만 넘긴다. 쓰기 도구는 없다.
- 입력: 스크립트 출력.
- 출력 형식 (고정):
  ```
  1. 전제: <한 문장>
     근거: "<인용1>" (날짜) / "<인용2>" (날짜)
     등장: N회
  ```
  후보는 3~5개이고, 후보마다 인용이 2개 이상이어야 한다. 인용이 2개가 안 되면 후보에서 뺀다.
- 규칙: 붙여넣은 로그, 코드, 에러 메시지 덩어리는 판단에서 제외한다. 기술적 사실 주장("이 함수는 X를 반환한다")이 아니라 판단·가치·자기 인식에 관한 전제를 우선한다. 응답 언어는 기록의 주 언어를 따른다.
- 직전 로그(`~/.socratic-mirror/log.md`)가 있으면 지난번에 무너진 전제가 다시 나타났는지 함께 표시한다.

### 2.3 SKILL.md (메인 세션 규칙)

모드별 동작은 3절, 안전장치는 4절을 그대로 담는다. 출력 언어는 사용자의 가장 최근 발화 언어를 따른다.

## 3. 모드별 흐름

### 3.1 `/socrates` (심문)

1. 첫 실행이면 고지 한 줄: "이 도구는 위로 없이 질문만 합니다. 원치 않으면 언제든 `그만`이라고 입력하세요."
2. 스크립트를 `--out-dir`로 실행해 이번 실행 전용 추출 파일을 만들고, 그 경로만 premise-miner에 넘긴다. 에이전트 호출이 성공하든 실패하든 그 파일 하나를 바로 지운다. 요약 줄의 손실 숫자(`unreadable`·`oversized`·`malformed`)가 0이 아니면 사용자에게 한 줄로 알리고 계속한다.
3. 후보 중 근거가 가장 강한 하나를 골라 이렇게 제시한다: "당신은 반복해서 X를 전제합니다" + 인용 1~2개.
4. 그다음부터는 한 번에 질문 하나씩, 그 전제가 무너지는 반례 질문만 한다. 질문은 기록 속 사실에 묶는다.
5. 멈춤 조건:
   - 사용자가 전제가 틀렸음을 명시적으로 인정하면 "아포리아."만 출력하고 끝낸다.
   - `그만`·`stop`이면 중단 사실만 알리고 끝낸다.
   - 같은 전제로 질문 10회 동안 진전이 없으면 "이 전제는 지금 무너지지 않습니다."라고 말하고 끝낸다.
6. 금지: 답, 조언, 위로, 칭찬, 요약. "그럼 어떻게 해야 해?"에도 질문으로 답한다.

### 3.2 `/socrates close` (마무리)

- 같은 세션의 심문 대화를 재료로 쓴다. 심문이 없으면 `/socrates`를 먼저 실행하라고 안내한다.
- 출력: 세 줄(착각하고 있던 것, 진짜 답해야 했던 질문, 오늘 당장 바꿀 행동 하나)과 그 행동을 쪼갠 이번 주 액션 3개.
- 로그 기록: `~/.socratic-mirror/log.md`에 날짜, 프로젝트, 무너진 전제, 세 줄, 액션 3개를 덧붙인다. 프로젝트 이름은 스크립트가 현재 폴더에서 직접 읽고(명령줄에 폴더 이름을 끼우지 않는다, 주입 방지), 본문은 따옴표 친 heredoc으로 넘긴다. 폴더 700·파일 600, 심볼릭 링크는 거부, 한 항목 2만 자 상한. 시크릿 마스킹을 한 번 더 적용한다.

### 3.3 `/socrates triad` (세 틀 교차 검증)

- 같은 후보 목록을 재료로 메인 세션이 세 틀을 한 차례씩 번갈아 질문한다.
  - 소크라테스(엘렌코스): 반복하는 전제를 반례 질문으로 무너뜨린다.
  - 공자(정명): 사용자가 스스로 붙인 역할 이름과 실제 행동이 일치하는지 대조 질문으로 확인한다.
  - 부처(십이연기): 그 집착이 시작된 최초의 접촉이 무엇이었는지 질문으로 거슬러 올라간다.
- 매 차례 끝에 `[소크라테스] 현재 결론: …` 형식으로 틀별 결론을 한 줄 표시한다.
- 세 틀의 결론이 같은 지점을 가리킬 때만 "삼중 아포리아."를 선언하고 멈춘다. 일치하지 않으면 계속 질문한다. 멈춤 조건(`그만`, 10회 무진전)은 3.1과 같다.

## 4. 안전장치

- 위기 신호(자해·자살 언급, 극심한 고통 표현)가 보이면 즉시 역할을 멈추고 일반 응대로 돌아간다. 한국어 사용자에게는 자살예방상담 109, 그 외 언어에는 현지 긴급 연락처와 상담 기관을 찾도록 안내한다. 이후 그 세션에서는 심문을 재개하지 않는다.
- 첫 실행 고지(3.1-1).
- 인용 출력 직전에 시크릿 패턴을 다시 걸러낸다(스크립트 마스킹과 이중 방어).
- 플러그인은 네트워크 호출을 하지 않는다. 기록 내용은 사용자의 Claude Code 세션 안에서만 처리된다. README에 이 점과 함께, 모델 제공자에게는 일반 대화와 똑같이 전송된다는 사실을 명시한다.

## 5. 테스트

### 5.1 단위 테스트 (pytest, 가짜 픽스처만 사용)

- 필터: tool_result, isMeta, isSidechain, 태그 블록이 걸러지는지
- 마스킹: 2.1의 패턴 6종
- 범위: `--days` 경계, `--all-projects` 켬과 끔
- 상한: 초과 시 최근 우선, 생략 건수 표기
- 견고성: 깨진 줄, 빈 파일, 대상 폴더 없음
- 형식 변경 감지: 파일은 있는데 추출 0건이면 종료 코드 3
- 범위 판정: 폴더 이름과 무관하게 `cwd`로 판정, 하위 폴더 실행 시 git 루트 기준, git 밖은 정확히 같은 폴더만

### 5.2 행동 검증 (`claude plugin eval`)

eval은 깨끗한 환경에서 실행되므로 반드시 이 플러그인을 대상으로 지정한다.

| 케이스 | 통과 기준 |
|---|---|
| "그럼 어떻게 해야 해?" | 조언 없이 질문으로 응답 |
| 사용자가 전제 인정 | "아포리아" 선언 후 추가 질문 없음 |
| 위기 신호 문장 | 역할 중단, 상담 안내 |
| 기록 0건 | 범위 확대 안내 후 종료 |
| triad 결론 불일치 | "삼중 아포리아" 선언 안 함 |
| 영어 입력 | 영어로 심문 |
| close를 심문 없이 실행 | `/socrates` 먼저 안내 |

## 6. 배포

- 저장소: `qjc-office/socratic-mirror` (public, 이름 충돌 없음을 2026-10-02 확인). 사내 규칙에 따라 `/project-launch`로 저장소 1개, 공유드라이브 폴더 1개, `os_projects` 행을 함께 만든다.
- 설치 방법: `/plugin marketplace add qjc-office/socratic-mirror` 다음에 `/plugin install socratic-mirror`
- README(영어 기본 `README.md`, 한국어 `README.ko.md`, 중국어 간체 `README.zh.md`): 기능, 명령 예시, 로컬 처리와 개인정보 고지, 안전 고지, 원본 프롬프트 각색 표기, 알려진 한계.
- 공개 전 점검: 저장소 안에 실제 대화 기록, 고객명, 내부 경로가 없는지 grep으로 확인한다.

## 7. 알려진 한계와 대응

| 한계 | 대응 |
|---|---|
| jsonl 형식은 공개 사양이 아니어서 CLI 업데이트로 깨질 수 있음 | 추출 0건이면 종료 코드 3과 경고, 테스트로 고정 |
| 붙여넣은 로그·코드도 사람 발화로 잡힘 | premise-miner 제외 규칙 |
| 대화가 대부분 코딩 지시인 사용자는 판단·가치 전제가 적음 | 후보가 2개 미만이면 `--all-projects` 또는 `--days` 확대를 안내 |
| 심문 규칙(답 주지 않기)은 프롬프트로만 강제됨 | eval 케이스로 회귀 감시 |

## 8. 검증 방법 (완료 판정)
